🧠 Brain Tumor Detection and Classification using Deep Learning

A hybrid deep learning framework for **automated multi-class brain tumor classification from MRI images** using a dual-branch architecture combining **ConvNeXt-Base, EfficientNetB4, and Convolutional Block Attention Module (CBAM)**.

The proposed model is designed to learn both **global contextual features** and **fine-grained tumor characteristics**, while CBAM helps the network focus on the most informative regions of MRI scans.



 📌 Project Overview

Brain tumor classification from MRI scans is challenging because tumor size, shape, location, and intensity can vary significantly. Manual interpretation can also be time-consuming and dependent on radiologist expertise.

This project proposes a **computer-aided deep learning approach** that automatically classifies MRI images into four categories:

* 🧠 Glioma
* 🧠 Meningioma
* 🧠 Pituitary Tumor
* ✅ No Tumor

The model uses two parallel feature-extraction branches:

MRI Image → ConvNeXt-Base + EfficientNetB4 → CBAM Attention → Feature Fusion → Classification → Tumor Class**

The system is intended as a **computer-aided decision-support tool** and not as a replacement for professional medical diagnosis.



 🎯 Objectives

* Automatically classify brain tumors from MRI images.
* Extract both global and local image features.
* Improve feature representation using attention mechanisms.
* Combine complementary features from two deep learning architectures.
* Evaluate the model using accuracy, precision, recall, and F1-score.
* Develop a robust framework that can assist computer-aided clinical decision making.



 🏗️ Proposed Architecture

The proposed framework consists of the following major components:

 1. Image Preprocessing

MRI images are:

* Resized to a consistent resolution.
* Normalized.
* Divided into training, validation, and testing datasets.

The model receives MRI images belonging to four classes.

2. ConvNeXt-Base Branch

ConvNeXt-Base extracts **high-level global and contextual features** from the MRI images.

It uses operations including:

* Patch embedding
* Depthwise convolution
* Layer normalization
* GELU activation

This branch focuses on broader structural information.

 3. EfficientNetB4 Branch

EfficientNetB4 extracts **fine-grained local features** from the MRI images.

The branch uses:

* MBConv blocks
* Squeeze-and-Excitation modules
* Compound scaling

This allows the model to learn detailed tumor characteristics efficiently.

4. CBAM Attention Mechanism

The extracted feature maps are passed through **Convolutional Block Attention Module (CBAM)**.

CBAM contains:

* Channel Attention– identifies important feature channels.
* Spatial Attention – identifies important regions within the image.

This helps suppress less informative features and emphasize relevant tumor regions.

 5. Global Average Pooling

Attention-refined feature maps are passed through Global Average Pooling to obtain compact feature vectors.

 6. Feature Fusion

The feature vectors generated by ConvNeXt-Base and EfficientNetB4 are concatenated.

This combines:

* Global contextual information from ConvNeXt-Base
* Fine-grained local information from EfficientNetB4

 7. Classification

The fused representation is passed through fully connected layers followed by a **Softmax classifier**.

The final output belongs to one of four classes:


Glioma
Meningioma
Pituitary Tumor
No Tumor

 📊 Dataset

The project uses a publicly available **Brain Tumor MRI Dataset from Kaggle**.

The dataset contains four categories:

| Class      | Training | Testing |
| ---------- | -------: | ------: |
| Glioma     |     1401 |     402 |
| Meningioma |     1401 |     404 |
| No Tumor   |     1403 |     400 |
| Pituitary  |     1400 |     400 |

The paper reports **5,605 training images and 1,606 testing images**.

> Note: The source paper contains inconsistent totals in its dataset description/table. Before publishing exact dataset counts in the repository, verify the actual dataset split used by your code.

 🧪 Model Training

The proposed model is trained using:

* **Loss Function:** Categorical Cross-Entropy
* **Optimizer:** Adam
* **Epochs:** 20
* **Evaluation:** Accuracy, Precision, Recall, F1-score
* **Additional Evaluation:** Confusion Matrix and ROC Curve

Validation data is used to monitor model performance and help reduce overfitting.

## 🔍 Evaluation Metrics

The project evaluates the model using:

### Accuracy

Measures the proportion of correctly classified MRI images.

### Precision

Measures how many predicted samples of a class are actually correct.

### Recall

Measures how many actual samples of a class are correctly identified.

### F1-Score

Provides a balance between precision and recall.

The project also uses **confusion matrices and ROC curves** for detailed evaluation.
